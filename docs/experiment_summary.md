# Python 字符田字格绘制实验总结

## 一、实验目的

本次实验是《Python语言程序设计基础（第3版）》第196页程序练习题5.1，要求使用Python编写函数，通过字符方式绘制田字格，并根据输入的宽度参数调整田字格大小。

通过本次实验，主要学习Python函数的定义与调用、for循环、字符串拼接和重复运算，以及简单的输入异常处理。

## 二、实验过程

首先，我根据教材要求分析田字格的组成，发现可以使用加号（+）表示交点、减号（-）表示横线、竖线（|）表示纵向边界，再通过空格形成格子内部的空白区域。

接着，我编写了 `draw_grid(width)` 函数，将每个小格子的宽度作为参数，利用字符串重复运算生成横线和竖线，并使用嵌套for循环绘制4行4列的田字格。

完成基础功能后，我增加了用户输入功能，让程序能够根据输入的数字绘制不同大小的网格。同时增加了简单的异常处理，避免输入0或非整数时出现不合理的绘制结果。

## 三、测试过程与结果

为了验证程序功能，我进行了五组测试。

| 测试内容 | 输入值 | 实际结果 |
|---|---|---|
| 正常宽度 | 3 | 成功绘制4×4田字格 |
| 较小宽度 | 2 | 成功绘制较小田字格 |
| 较大宽度 | 5 | 成功绘制较大田字格 |
| 非法宽度 | 0 | 提示宽度必须为正整数 |
| 非整数输入 | abc | 提示请输入整数 |

五组测试结果均符合预期，说明程序能够根据宽度参数绘制不同大小的字符网格，并对两种常见的错误输入进行处理。

测试截图保存在 `docs/screenshots/` 文件夹中。

## 四、实验中遇到的问题

实验过程中，我主要需要考虑如何让田字格的横线和竖线正确连接，以及如何通过函数参数改变网格大小。

通过分析，我将横线和竖线分别定义为字符串，再使用循环重复输出，减少了重复编写print语句的工作量。

另外，我还发现程序不能只考虑正常输入，因此增加了宽度检查和try...except异常处理，使程序在输入不符合要求时能够给出提示。

## 五、实验收获

通过本次实验，我进一步熟悉了Python函数的定义和调用方法，也理解了函数参数在程序中的作用。

在绘制田字格的过程中，我练习了for循环、嵌套循环和字符串重复运算，认识到一些看起来复杂的字符图形，其实可以通过简单的规律和循环实现。

同时，通过测试不同宽度以及错误输入，我认识到编写程序不仅需要实现基本功能，还需要检查程序在不同输入情况下能否正常工作。

这次实验也让我进一步熟悉了VS Code和GitHub的使用，为以后完成Python编程作业积累了经验。

## 六、实验总结

本次实验完成了基于Python函数的字符田字格绘制，实现了通过输入宽度参数调整田字格大小的功能，并通过五组测试验证了程序的基本正确性。

通过实验，我巩固了函数、循环和字符串操作等基础知识，也提高了自己分析问题和调试程序的能力。
